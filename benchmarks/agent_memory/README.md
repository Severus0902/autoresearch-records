# Agent Memory Benchmark Scaffold

This folder contains the first scaffold for the Agentic Memory / Agentic RAG benchmark direction.

Working name:

```text
MemoAgentBench-Lite
```

Goal:

```text
Evaluate whether an LLM agent can write, update, retrieve, forget, and use memory across multi-session tasks.
```

Initial files:

- `task_schema.md`: candidate task JSON schema.
- `evaluation_protocol.md`: metrics and baseline protocol.

This is not tied to KG reasoning. The first implementation should be backend-agnostic and small-resource friendly.
